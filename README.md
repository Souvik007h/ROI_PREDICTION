# 🌱 ROI Prediction

An AI-powered farming profitability prediction system that estimates **Return on Investment (ROI)** based on farm details, agricultural operations, and financial inputs.

🔗 **Live Demo:** https://roi-prediction-1.onrender.com/

---

## 📌 Overview

**ROI Prediction** is a web-based machine learning application designed to help estimate the potential profitability of a farming operation.

Users provide information about:

* 🌾 Crop and farm details
* 🚜 Farming operations
* 💧 Irrigation and water usage
* 💰 Labour, seed, and total investment costs
* 📦 Expected yield

The system processes these inputs and generates an estimated **ROI value**.

---

## ✨ Features

* Multi-step interactive prediction interface
* Farm, operations, and financial input sections
* Machine learning-based ROI prediction
* Clean and responsive UI
* Real-time ROI prediction
* Deployed and accessible through Render

## 🚀 Run Locally

### 1. Clone the Repository

```bash
git clone https://github.com/Souvik007h/ROI_PREDICTION.git
cd ROI_PREDICTION
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the Application

```bash
python app.py
```

### 4. Open in Browser

Visit:

```text
http://127.0.0.1:5000
```

## 🎯 Objective

The goal of this project is to demonstrate how **machine learning and web technologies can be combined to support data-driven agricultural investment and profitability analysis.**

The system aims to provide users with an estimated ROI based on their farm characteristics, operational expenses, investment, and expected production.
